Featured Projects

1. Ajustable Benchtop Variable Power Supply

Objective

To design and construct a reliable, regulated DC variable power supply unit for testing and powering various electronic circuits, microcontroller boards, and prototype components with precise voltage and current control.

Technology stack and components

  • Step-Down Transformer: Steps down high AC mains voltage to a lower AC level.
  • Rectification & Filtering Stage: Converts alternating current (AC) to an unregulated direct current (DC) source using bridge rectifiers and filter capacitors.
  • DC-DC Step-Down Buck Converter (XL4016E1-Series): Efficiently regulates and steps down the DC voltage level.
  • Potentiometers: Provides manual user adjustment for precise voltage and current regulation.
  • Digital Panel Meter: Displays real-time output voltage and current metrics.
  • DC Cooling Fan: Provides thermal management to prevent overheating of internal components and the transformer during extended operation.
  • DC Cooling Fan: Dual binding posts for secure connection to external circuits.

Functionality

  1. Power Conversion: The step-down transformer reduces input AC voltage, which is subsequently converted into an unregulated DC supply.
  2. Power Conversion: The DC-DC buck converter module processes the unregulated input, allowing users to fine-tune the output parameters smoothly via potentiometers.
  3. Real-Time Monitoring: The integrated digital display provides continuous visual feedback of the active voltage and current output levels.
  4. Thermal Management: A dedicated DC cooling fan activates to dissipate heat and maintain optimal operating temperatures within the enclosure.
  5. Versatile Delivery: Delivers stable, adjustable DC power through the output terminals, serving as a fundamental workbench tool for hardware testing and circuit debugging.

2.IoT-Based Web-Controlled Relay Switch

Objective

To design and implement a wireless IoT control system using an ESP32 microcontroller that hosts an embedded web server, enabling users to remotely toggle electrical appliances and loads via an interactive web interface.

Technology Stack & Components

  • ESP32 Microcontroller: Serves as the central processing unit with integrated Wi-Fi capabilities to host the web server and process client requests.
  • Relay Module: Isolates the low-voltage microcontroller logic from high-current or AC/DC loads, physically switching the connected appliance on or off.
  • Resistors & Capacitors: Provide current limiting, signal conditioning, and voltage stabilization across the circuitry.
  • Indicator LEDs: Offer real-time visual feedback for power status and relay activation.
  • Web Interface (HTML/CSS): Renders the user-facing control panel featuring the interactive switch element.

Functionality

  1. Web Server Hosting:The ESP32 connects to a local wireless network and hosts a lightweight web page containing an interactive interface switch.
  2. Multi-Device Accessibility:Users can access the hosted control page from any networked device, including smartphones, laptops, or tablets.
  3. Command Processing:Clicking the switch on the webpage sends an HTTP request command to the ESP32 microcontroller.
  4. Load Control:Upon receiving the signal, the ESP32 toggles its digital output pin to trigger the relay module, opening or closing the circuit to operate the connected load (such as a fan or LED).
  5. Status Indication:Integrated indicator LEDs illuminate to display the active operational state of the system and relay trigger events.

3.IoT-Based Smoke and LPG Gas Detector Alarm System (ESP32) Objective

To design and implement an automated safety monitoring system using an ESP32 microcontroller that detects hazardous smoke and LPG gas leaks, provides local audio warnings, dispatches instant SMS notifications to emergency contacts, and supports real-time web monitoring.

Technology Stack & Components

  • ESP32 Microcontroller:Serves as the central processing unit, analyzing incoming sensor data, executing alert logic, and hosting the embedded web page.
  • Smoke and LPG Gas Sensor:Continuously monitors the surrounding air quality to detect combustible gases, liquefied petroleum gas (LPG) leaks, and smoke concentrations.
  • Buzzer:Provides an immediate local audible alert when hazardous threshold levels are exceeded.
  • Communication Module / SMS Gateway:Transmits automated warning messages to the system owner and all pre-listed emergency contacts.
  • Embedded Web Server Interface:Displays live gas and smoke detection metrics through a browser-accessible dashboard.

Functionality

  1. Continuous Environmental Sensing:The gas and smoke sensor actively monitors the local environment for anomalies in air composition.
  2. Signal Transmission:Upon detecting smoke or gas concentrations above a safe threshold, the sensor sends a trigger signal to the ESP32.
  3. Local Alarm Trigger:The ESP32 immediately activates the buzzer to sound an audible warning for occupants in the immediate area.
  4. Automated Emergency Messaging:The system sends real-time SMS alerts to the owner and designated contact list to ensure prompt notification even when away.
  5. Web-Based Monitoring:The ESP32 hosts a live status page that allows users to monitor current gas and smoke levels remotely via any connected network device.
